# curate-shoot prompt — v1 (2026-10-26 · P3.0 model-agnostic curation contract)
# This file is the CONTRACT the operator's active multimodal model (GLM-5.3
# Flash, Nemotron-VL, proxy-routed — anything) answers for the shoot-curation
# pass. It is read by the model in-session; scripts/curate-shoot.js VALIDATES
# the answer and caches it into assets/raw/optimized/vision-manifest.json.
# No SDK, no API key, no vendor code is involved. Edit the version line
# whenever the contract changes. Keep the vocabulary CLOSED — every enum is
# enforced fail-closed by the script.

You are the vision-curation pass for a static social pipeline (Direct Kitchens).
Read EVERY image in assets/raw/optimized/ listed by `node scripts/curate-shoot.js`
(it prints the pool with deterministic metrics: aHash burst clusters, hero
crop-loss candidates, EXIF availability). Judge ONLY what the deterministic
tier cannot: semantics. Answer strictly and tersely, as JSON.

## Per-image judgments
For each file emit:
- "density":     "ACTIVE_COMPLEX"  — open drawers, jars, handles, cluttered mid-ground;
                 or "CALM_PLANAR"  — smooth frontage, flat stone/tile grain, quiet wall run.
- "focusZone":   "HARDWARE_PULL" (handles/knobs/pull-outs) | "SURFACE_TEXTURE"
                 (benchtop/tile/stone grain) | "JOINERY_JUNCTION" (door/corner/shelf
                 meeting) | "APPLIANCE" (ovens/cooktop/hood) | "NONE".
- "subject":     short abstract assembly description, NO marketing adjectives —
                 e.g. "open spice pull-out with jars", "sage shaker fronts with knobs".
- "tones":       "primary" + "secondary", each { "hex": "#rrggbb", "family": one of
                 sage | warm-timber | crisp-white | charcoal | brass | stone-greige | other }.
- "detailNote":  one grounded sentence (future alt-text aid).

## Pairing judgment (1+2 Grid / duo: top hero + two bottom detail panes)
Emit "pairing" with:
- "hero":        MUST be one of the printed Rule-A candidates (crop-loss tie band).
- "bl", "br":    the two detail panes. HARD BANS: never two frames of the same
                 burst cluster (script enforces); never the same object/assembly
                 in both panes (twin-drawer defect — permanent ban).
- "echoPane":    "bl" or "br" — the pane echoing the hero's accent tone (its tone
                 family must genuinely overlap the hero's — script verifies).
- "rationale":   1-2 sentences.
- "ruleVerdicts": { "B": "PASS|FAIL", "C": "PASS|FAIL", "D": "PASS|FAIL" } —
                 B subject diversity, C density inversion (ACTIVE ↔ CALM),
                 D colour resonance. Any FAIL refuses the whole pairing.

## Output shape (exactly; save as assets/raw/optimized/vision-intake.json)
{
  "model": "<your model id/name>",
  "vision": { "<file.jpg>": { density, focusZone, subject, tones: { primary, secondary }, detailNote } },
  "pairing": { "hero": "<file.jpg>", "bl": "<file.jpg>", "br": "<file.jpg>",
               "echoPane": "bl", "rationale": "...", "ruleVerdicts": { "B": "PASS", "C": "PASS", "D": "PASS" } }
}
Then run: node scripts/curate-shoot.js --intake assets/raw/optimized/vision-intake.json
